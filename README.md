# IACH-AIS-Project

## Data Source

The AIS fishing trajectories dataset used by this project was obtained from
Kaggle:

<https://www.kaggle.com/datasets/thedevastator/detailed-labelled-fishing-trajectories-from-ais>

The local copy is expected at:

`CODE/database/128_fishing_trajs.csv`

The dataset is not included in this repository because the CSV file exceeds
GitHub's 100 MB file-size limit. It must be downloaded separately from the
Kaggle source above before running the project.
